# Internal Adjustment — Business Vocabulary (Synthetic Demo)

## Category context
An internal adjustment is a request classified as an adjustment within an internal operational process. The label identifies a category of request; it does not by itself guarantee that the adjustment has been posted, reconciled, or approved.

## Technical mapping boundary
The Operation types catalog provides the authoritative mapping between numerical category keys and category labels. This glossary does not define the numerical key, determine permitted amount values, or say when an internal adjustment can be registered.

## Scope and limitations
This vocabulary entry supplies context for interpreting catalog labels in a candidate rule. The eligibility conditions must still come from the SQL workflow and other applicable controls.
